# 홍보영상 제작 규칙

새 홍보영상은 이 문서를 기준으로 만듭니다. 규칙이 바뀌면 이 문서부터 고칩니다.

## 1. 내용과 구성

| 항목 | 규칙 |
| --- | --- |
| 브랜드 | 서비스명은 **온더리밋**입니다. 타이틀, 주소창, 자막 어디에도 "F1"을 붙이지 않습니다. |
| 로고 | 타이틀과 아웃트로에는 텍스트 대신 `client/public/brand/`의 **배지 로고**를 씁니다. 로고를 늘이거나 색을 바꾸지 않습니다. |
| 화면 구성 | **모바일 우선.** 모바일 장면을 먼저 보여 준 뒤, 영상 뒤쪽에서 "데스크탑에서는 더 넓게, 한눈에"를 표현합니다. 데스크탑과 모바일이 모두 들어가야 합니다. |
| 주소창 | 브라우저 프레임의 주소창에는 URL(localhost 등) 대신 서비스명 **온더리밋**을 넣습니다. |
| 자막 | "DESKTOP 01"처럼 번호를 붙인 말머리를 쓰지 않습니다. 장면마다 **메뉴명과 기능 설명**만 넣습니다. |
| 첫 타이틀 | 로고와 한 줄 문구만 넣습니다. DESKTOP / MOBILE / 시즌 같은 칩은 넣지 않습니다. |
| 아웃트로 | **기술 스택은 넣지 않습니다.** 크레딧은 라이선스가 출처 표기를 요구하는 이미지·음원만 적습니다. 예를 들어 CC BY 사진은 넣고, 표기 의무가 없는 Mixkit 항목은 뺍니다. |
| 분위기 | 모터스포츠다운 다이나믹한 참조 이미지(사진, 스톡 영상)와 사운드(엔진음, 휘시, 임팩트)를 넣습니다. |
| 테마 | 앱 화면은 **라이트 테마**로 녹화합니다. |
| 길이·음악 | 영상은 **정확히 90초**입니다. 90초 길이에 맞는 **곡 하나**를 자르거나 이어 붙이지 않고 끝까지 끊김 없이 씁니다. |
| 기존 파일 | 이전 영상은 지우지 않습니다. 새 영상은 새 파일명으로 추가합니다. |

## 2. 소스와 라이선스

- 저작권 문제가 없는 **무료** 사운드·이미지·영상만 씁니다.
- **Mixkit:** 음악, 효과음, 스톡 영상은 Free License 항목만 씁니다. 스톡 영상에 섞여 있는 광고 사용 제한 항목(**Restricted License**)은 쓰지 않습니다.
- **사진:** CC0, 퍼블릭 도메인, CC BY만 씁니다. CC BY-SA, NC, ND는 쓰지 않습니다.
  - CC BY 사진은 아웃트로에 촬영자와 라이선스를 적습니다.
  - README에는 원본 링크와 변경 사항(자르기, 확대, 보정 등)까지 적습니다.
- **원본 파일:** 내려받은 음원·영상·사진 원본은 저장소에 커밋하지 않습니다. Mixkit 라이선스는 음원을 따로 떼어 재배포하는 것을 금지합니다.
- **상표·초상:** 사진에 나오는 팀·스폰서 로고와 실제 드라이버는 CC BY로 허락되는 범위가 아닙니다. 상업적으로 쓸 때는 따로 확인합니다.
- **서체:** 상업적 사용과 영상 삽입이 허용되는 무료 서체만 씁니다. 지금은 Pretendard(SIL OFL 1.1)를 씁니다.

## 3. 녹화

- **데이터:** 실제 시즌 데이터(Jolpica-F1 API, FastF1)를 불러온 상태에서 녹화합니다.
  - 외부 접속이 막혀 샘플 데이터를 써야 한다면, 그 사실을 영상과 README에 적습니다.
- **녹화 도구:** Playwright의 CDP 스크린캐스트로 녹화합니다.
  - 데스크탑은 1920×1080입니다.
  - 모바일은 **390×844**(DPR 2)입니다. Playwright의 iPhone 기본 뷰포트(390×664)는 폰 프레임 비율과 맞지 않아서 쓰지 않습니다.
- **조작 표시:** 클릭은 커서로, 탭은 원형 리플로 보여 줍니다.
- **로딩 화면:** 차트가 로딩되는 빈 화면은 편집에서 잘라냅니다.

## 4. 편집

- **출력:** 1920×1080, 30fps, H.264(CRF 18) + AAC 192kbps입니다.
- **음악 배치:**
  - 곡의 원래 엔딩이 영상 끝에 오도록 시작 시점을 맞춥니다.
  - 인트로에서는 스타트 라이트가 꺼지는 순간 음악이 시작됩니다.
  - 사진 몽타주 컷은 비트에 맞춥니다.
- **장면 전환:**
  - 앱 화면끼리는 빨간 사선 와이프로 넘어갑니다.
  - 사진 전환 화면과 이어질 때는 화면이 번쩍이는 플래시로 넘어갑니다.
  - 전환마다 효과음을 넣고, 효과음이 나올 때 음악 볼륨을 살짝 낮춥니다.
- **프레임:** 데스크탑 화면은 브라우저 프레임에, 모바일 화면은 폰 프레임에 넣습니다.
- **자막 위치:** 데스크탑 장면은 상단 한 줄, 모바일 장면은 폰 옆에 제목·설명·핵심 기능을 넣습니다.

## 5. 결과물

- `promo/`에 다음을 넣습니다.
  - 영상
  - 대표 이미지(`poster-vN.jpg`)
  - 제작 스크립트(`promo/scripts/vN/`)
- `promo/README.md`에 구성표(시간대별 내용), 사용한 소스와 라이선스, 다시 만드는 방법을 적습니다.

## 6. 완료 전 확인

- [ ] 일정 간격(3–4초)으로 프레임을 뽑아 전체 흐름을 확인했다.
- [ ] 영상 길이가 정확히 90.00초이다.
- [ ] 오디오에 끊기는 곳이 없고, 음악이 곡의 엔딩으로 끝난다.
- [ ] 화면 어디에도 "F1" 표기나 localhost 주소가 없다.
- [ ] 아웃트로에 기술 스택이 없고, 출처 표기가 필요한 크레딧만 있다.
- [ ] README의 출처 표와 영상 아웃트로의 크레딧이 서로 맞다.
